# Kitchen Desk

Public site for the **Kitchen Desk** Pinterest + Amazon Associates pilot.

- Brand only — not linked to Value Added Accountancy
- Pages: home, about, privacy, affiliate disclosure
- Static HTML/CSS (free to host)

## Local preview

```bash
cd ~/Projects/kitchen-desk
python3 -m http.server 5173
```

Open http://localhost:5173

## Deploy (GitHub Pages — £0)

1. Create a GitHub repo (e.g. `kitchen-desk`) and push this folder
2. Settings → Pages → Source: **Deploy from a branch** → `main` / root
3. Site URL will be like `https://<user>.github.io/kitchen-desk/`
4. Use that URL for:
   - Pinterest Business profile website + claim
   - Amazon Associates website list
   - Pinterest developer app “company website” / privacy policy (`…/privacy.html`)

## Custom domain (optional later)

Point a domain (e.g. `kitchendesk.uk`) at GitHub Pages when you want it.
